A proper file manager for nova.storage

Nova puts your nova.storage files in a window that works like GNOME Files: a sidebar, a path bar, grid and list views, drag and drop, and the usual shortcuts. On your computer and on your phone.

It copies GNOME Files where it can, down to the keyboard shortcuts. On Linux it uses your icon theme too, so it looks like the rest of your desktop.

Works like GNOME Files

  • Grid and list viewsZoom, sort, show hidden files, drag a box to select.
    Ctrl+Scroll
  • Path barType a location, or go back, forward and up.
    CtrlL
  • SearchBelow the current folder, or everywhere at once with Search Everywhere.
    CtrlF
  • Quick previewImages, video, audio and text, without downloading them first.
    Space
  • UndoRenamed or moved the wrong thing? Undo works for rename, move and trash.
    CtrlZ
  • Several windowsCut, copy and paste between them; middle-click a folder to open it in a new one.
    CtrlN

Your files, wherever they are

  • Drag and dropDrop files or whole folders onto the window to upload them. On Linux, drag them back out onto your desktop.
  • Nothing gets overwrittenTransfers run in the background with progress, speed and a cancel button. A clashing name becomes “name (copy)”.
  • Trash on the serverDeleted files go to a trash in your storage, so you can restore them from any device.
  • Your own sidebarDrag folders into the sidebar and reorder them. The bookmarks are the same ones the nova.storage website uses.
  • Public linksTurn sharing on from the Properties dialog, which also shows folder sizes and checksums.
  • Usage at a glanceSettings shows your storage, transfer and download graphs, and can set up a sensible folder layout.

Linuxx86_64 · GTK 4 and WebKitGTK 6.0 This device

Quick install updates itself

curl -fsSL https://raw.githubusercontent.com/jevido/nova/main/install.sh | sh

Installs into your home directory, no sudo. Nova shows up in your app launcher.

Or pick a package

  • Portablenova-linux-amd64.tar.gzupdates itself
  • Arch / Omarchy.pkg.tar.zst
  • Debian / Ubuntu.deb
  • Fedora / RHEL.rpm
  • AppImageany distro

The packages tell you when a new version is out; the AppImage gives you a download link.

Debian / Ubuntu 24.04+
sudo apt install libgtk-4-1 libwebkitgtk-6.0-4
Arch
sudo pacman -S gtk4 webkitgtk-6.0
Fedora
sudo dnf install gtk4 webkitgtk6.0
WindowsWindows 10 and 11 · 64-bit This device
Download Installer

Installs for your user account, so no admin rights needed. Nova goes in the Start menu and updates itself.

  • Portablenova-windows-amd64.exeupdates itself

“Windows protected your PC”? Nova isn't code-signed yet, so SmartScreen doesn't know it. Click More info, then Run anyway. You only need to do this once.

AndroidAndroid 5.0 or newer · 64-bit ARM This device
Download APK
  1. Open this page on your phone and tap Download APK.
  2. Tap the file when the download finishes.
  3. The first time, Android asks you to allow installs from your browser. Allow it, then tap Install.

From then on Nova updates itself: when a new version is ready, tap Install on the notification.

iPhone and iPadiOS 15 or newer · sideloaded This device
Download IPA
  1. Install AltStore (or SideStore) on your iPhone, or Sideloadly on your computer.
  2. Download nova-ios.ipa and open it with that app. Sign in with your Apple ID when it asks; it signs Nova for your device.
  3. The first time, allow the developer profile under Settings › General › VPN & Device Management, and turn on Developer Mode if iOS asks.

With a free Apple ID the app has to be refreshed every 7 days; AltStore and SideStore do that for you. Nova isn't on the App Store or TestFlight. It tells you when a new version is out, and you install that the same way.

No macOS build yet. Want to help? The source is on GitHub.

Updates

  • Downloaded in the backgroundNova checks for a new version shortly after it starts and every 6 hours, verifies it against the release's checksums, then asks you to restart when it suits you.
