What it does

Nova copies GNOME Files where it can, down to the keyboard shortcuts. On Linux it uses your icon theme too, so it looks like the rest of your desktop.

Upload by dragging drag & drop
Drop files or whole folders onto the window. Transfers run in the background with progress, speed and a cancel button.
Undo Ctrl Z
Renamed or moved the wrong thing? Undo works for rename, move and trash.
Preview Space
Look at images, video, audio and text without downloading them first.
Search Ctrl F
Searches the current folder and everything below it.
Your own sidebar
Drag folders into the sidebar and reorder them. The bookmarks are the same ones the nova.storage website uses.
Trash on the server
Deleted files go to a trash in your storage, so you can restore them from any device.
Public links
Turn sharing on from the Properties dialog, which also shows folder sizes and checksums.
Usage at a glance
Settings shows your storage, transfer and download graphs, and can set up a sensible folder layout.
Light and dark
Follows your system, or pick one. Grid or list, zoom with Ctrl + scroll, several windows.
Updates itself
New versions are downloaded and checked against the release checksums in the background. You restart when it suits you.

Get Nova

Pick your platform. Every download comes from GitHub Releases and is listed in its checksums.txt.

Linux

x86_64 · GTK 4 + WebKitGTK 6.0

Quick install updates itself

curl -fsSL https://raw.githubusercontent.com/jevido/nova/main/install.sh | sh

Installs into your home directory. No sudo, and Nova shows up in your app launcher.

Or grab a package

  • Portable.tar.gz
  • Arch / Omarchy.pkg.tar.zst
  • Debian / Ubuntu.deb
  • Fedora / RHEL.rpm
  • AppImageany distro
Missing GTK 4 / WebKitGTK?
Debian / Ubuntu 24.04+
sudo apt install libgtk-4-1 libwebkitgtk-6.0-4
Arch
sudo pacman -S gtk4 webkitgtk-6.0
Fedora
sudo dnf install gtk4 webkitgtk6.0

Windows

Windows 10 & 11 · 64-bit
Download installernova-windows-amd64-setup.exe

Installs for your user account, so no admin rights needed. Nova goes in the Start menu and updates itself.

Or run it without installing updates itself

  • Portable.exe
“Windows protected your PC”?

Nova isn't code-signed yet, so SmartScreen doesn't know it. Click More info, then Run anyway. You only need to do this once.

Android

Android 5.0+ · 64-bit ARM
Download APKnova-android-arm64.apk
  1. Open this page on your phone and tap Download APK.
  2. Tap the file when the download finishes.
  3. The first time, Android asks you to allow installs from your browser. Allow it, then tap Install.

From then on Nova updates itself: when a new version is ready, tap Install on the notification.

On your computer? Scan this with your phone to download.

iPhone & iPad

iOS 15+ · sideloaded
Download IPAnova-ios.ipa
  1. Install AltStore (or SideStore) on your iPhone, or Sideloadly on your computer.
  2. Download nova-ios.ipa and open it with that app. Sign in with your Apple ID when it asks; it signs Nova for your device.
  3. The first time, allow the developer profile under Settings › General › VPN & Device Management, and turn on Developer Mode if iOS asks.

With a free Apple ID the app has to be refreshed every 7 days; AltStore and SideStore do that for you. Not on the App Store or TestFlight yet.

No macOS build yet. Want to help? Nova is open source.

Signing in

Use your nova.storage username and password, or paste an API key. There's nothing else to set up.
