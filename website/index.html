Feels like home.
Because it's modelled on it.

Nova takes its cues from GNOME Files: headerbar and path bar, places sidebar, icon and list views, right-click menus and the shortcuts your fingers already know. On the desktop it even uses your system icon theme, so it fits right in.

⇅

Drag, drop, done

Drop files or whole folders from your desktop onto the window to upload them. Transfers run in the background with progress, speed and cancel.

↶

Undo everything

Renamed the wrong file? Moved it somewhere silly? Ctrl+Z undoes rename, move and trash.

◉

Quick preview

Hit Space to peek at images, video, audio and text without downloading a thing.

🗑

Trash that syncs

Deleted files go to a trash on the server, so you can restore them from any device.

⌕

Find it fast

Search the current folder and everything below it with Ctrl+F. Star files and bookmark folders for the sidebar.

🔗

Share in a click

Flip on a public link from the Properties dialog. You also get folder sizes and checksums there.

◐

Light & dark

Follows your system theme, or pick one yourself. Grid or list, zoom with Ctrl+scroll, multiple windows.

↻

Keeps itself fresh

Nova checks for new versions, downloads and verifies them in the background, then asks you to restart.

Get Nova

Pick your platform. Every download comes from GitHub Releases and is listed in its checksums.txt.

Linux

x86_64 · GTK 4 + WebKitGTK 6.0

Quick install updates itself

curl -fsSL https://raw.githubusercontent.com/jevido/nova/main/install.sh | sh

Installs into your home directory. No sudo, and Nova shows up in your app launcher.

Or grab a package

  • Portable.tar.gz
  • Arch / Omarchy.pkg.tar.zst
  • Debian / Ubuntu.deb
  • Fedora / RHEL.rpm
  • AppImageany distro
Missing GTK 4 / WebKitGTK?
Debian / Ubuntu 24.04+
sudo apt install libgtk-4-1 libwebkitgtk-6.0-4
Arch
sudo pacman -S gtk4 webkitgtk-6.0
Fedora
sudo dnf install gtk4 webkitgtk6.0

Android

Android 5.0+ · 64-bit ARM
Download APKnova-android-arm64.apk
  1. Open this page on your phone and tap Download APK.
  2. Tap the file when the download finishes.
  3. The first time, Android asks you to allow installs from your browser. Allow it, then tap Install.

From then on Nova updates itself: when a new version is ready, tap Install on the notification.

On your computer? Scan this with your phone to download.

Windows and macOS aren't available yet. Want to help? Nova is open source.

Sign in and go.

Use your nova.storage username and password, or paste an API key. That's the whole setup.
